# Nexus Pad + DrumPad

Nexus Pad + DrumPad is a React/Vite music sketchpad built with Tone.js. It combines atmospheric synth pads, selectable sound presets, a metronome, tap tempo, and an electronic drum pad with configurable effects.

## Features

- Polyphonic pad notes with multiple presets
- Drum pad with kick, snare, clap, hat, tom, rim, FX, and crash sounds
- Drum effect presets
- Metronome with rhythm subdivision and tap tempo
- Built with React, Vite, and Tone.js

## Run Locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
